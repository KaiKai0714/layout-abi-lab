# Security

This project executes GPU kernels and may invoke Docker. Review container images and
commands before running them on shared infrastructure. Do not include credentials,
private paths, hostnames, or proprietary profiler traces in public result submissions.

Report security-sensitive issues through the repository's private vulnerability
reporting page rather than opening a public issue:

https://github.com/KaiKai0714/layout-abi-lab/security/advisories/new

If private vulnerability reporting is unavailable, contact
`ethankai0714@gmail.com`.
