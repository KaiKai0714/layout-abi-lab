# Code of Conduct

Project participants are expected to communicate respectfully, report results honestly,
and distinguish measured evidence from inference. Harassment, fabricated measurements,
selective deletion of valid negative results, and undisclosed manipulation of benchmark
conditions are not acceptable.

The maintainer may remove contributions or restrict participation when these
expectations are violated. Reports may be opened as a repository issue. If a report
contains sensitive information, use the repository's private reporting page documented
in `SECURITY.md`.
